posts, included here strictly as a STUDY LIBRARY for design-DNA analysis.

- These works are NOT licensed under this repository's Apache-2.0 license.
- The OS itself forbids reproducing any reference brand's name, logo,
  handle, or identity in generated output — references define composition
  ("the stage"), never content.
- If you are a rights holder and want an image removed, open an issue and
  it will be taken down immediately.

When you fork this project, you are encouraged to replace this library
with references you have collected yourself via the intake flow.
